## Security and operational exclusions

Candidates are trusted local code executed with the current user's permissions and host network access. Private roots, exact Git admission, process groups, loopback authentication, CSP, and bounded capture are not a sandbox. Same-user malware, hostile browser extensions, deliberately detached descendants, malicious native tooling, kernel compromise, and arbitrary repository behavior are outside the claim.

The default export omits known fixture-profile sensitive fields and scans selected values, but it does not prove arbitrary-secret absence. Raw export is dangerous. Named credential scans, secrets overrides, package license listings, and binary marker scans are bounded diagnostics—not a vulnerability scan, SBOM, legal review, provenance attestation, or confidentiality proof.

The only natively exercised runtime is Darwin arm64 on the exact recorded host. Linux is compilation-only. The binary is unsigned, unnotarized, unpublished, and not byte-reproducible because the accepted Darwin linker emits a fresh Mach-O UUID.
