## Red-team corrections carried into implementation

U5 did not rubber-stamp P05. Independent architecture, reducer, wire, replay-boundary, and mutation lanes found these load-bearing corrections:

1. The original package rule was impossible in Go: a pure `internal/reduce` package cannot consume a concrete opaque type from a store that already imports it, while a reducer-owned interface would be forgeable. The locked direction is `reduce draft -> store publication/capability -> outward reduction finalizer`.
2. Reduction ordering is a new adapter-level artifact. Adding presence dimensions to the sealed U3/U4 stimulus measures would redigest prior stimuli and invalidate their receipts. U5 instead defines canonical reduction-measure tuples with their own definition digests.
3. A reducer set binds rule names/versions, the measure definition, and a policy-scope digest containing fixed semantic anchors, pin sets, execution shape, and enabled transform classes. Exact reducible member values are instead bound by the run's stimulus and proposal identities. `ONE_MINIMAL_UNDER` quantifies only over the final stimulus's direct neighborhood under that policy.
4. The pristine U3/U4 reference stimuli were designed as minimal observation probes and need not contain irrelevant reducible noise. U5 uses checked-in noisy variants for the required smaller preserving witnesses.
5. Grade precedence is exact: a live run with the matching compiled-`WorldPlan` shrink budget, no limitations, and a valid durable sweep capability earns `ONE_MINIMAL_UNDER`; otherwise an accepted smaller witness is `BEST_KNOWN`; otherwise the result is `UNCHANGED` with limitations. A missing authority selects the explicit weak path, while an offered invalid authority or an ad-hoc unbound budget is refused. No unresolved or cancelled path can earn the strong grade.
6. Empty direct-neighbor enumeration is non-vacuous authority only when enumeration completed and the exact empty draft was atomically published and reopened.
7. Rule order and within-rule transform order are semantic search policy. The reducer-set identity binds declared rule priorities, every proposal binds a bounded transform priority, and the generic engine canonicalizes by those values rather than silently substituting lexical rule or child-digest order.
8. An apparently complete later sweep cannot erase any earlier unresolved, cancelled, stale, or budget-limited observation. Every recorded limitation keeps the run on the weak-grade path.
9. Content-addressed publication is create-if-absent. The Darwin reference store uses a same-directory hard link so a racing publisher cannot replace an existing address, then reopens exact bytes before issuing process-local authority.
10. Serialized replay is intent replay, not capture replay. A transcript commits to declared baseline map identities and four sorted evidence lists, but executing replay additionally requires the exact opaque compare-owned `DivergentBaseline` and anchors the first archived parent to that baseline stimulus before any callback. The callback must return structurally valid same-domain noncolliding evidence; receipts do not prove physical execution, freshness, proposal correspondence, or behavioral reproduction and cannot construct an evaluation or grade.
11. Once an evaluator callback runs, malformed, reused, or over-budget output becomes a terminal `UNRESOLVED` transcript entry rather than disappearing. Structurally valid same-domain nonreused partial lineage is retained when admissible; invalid map authority is discarded. A complete map-backed result must report exactly its typed attempt-evidence cardinality. An allowance breach records the callback-reported count and blocks completion; unresolved/error-only counts remain a trusted evaluator-edge assertion rather than proof of physical work.
12. The five terminal protocol-refusal reason codes are internal authority. Public evaluation constructors reject caller-authored use, while the reducer converts that attempt into `INVALID_EVALUATOR_RESULT` and records it visibly.
13. The strict transcript parser enforces engine-reachable accounting and control flow: all-or-none unresolved evidence domains, no observed map without charged trials, no post-budget continuation, no self-neighbor, exact parent/measure continuity, reserved protocol-refusal and final-sweep terminal limitation converses, and no continuation after a non-`CHANGES` final-sweep result.
14. The reviewed mutation contract contains 22 distinct source fault injections. The harness rejects duplicate source mutations, compilation failures cannot masquerade as semantic kills, and every mutant uses a private exact seed plus fresh A/B/A closure. The added accounting mutant removes the resolved-map attempt-cardinality fence and must be killed by its dedicated top-level test.
15. The real CLI physical `BEST_KNOWN` fixture consumes three nine-trial evaluations, accepts one preserving shrink, then reaches the exact candidate-trial fence during the next search. It retains the smaller witness while refusing final-sweep completion or a strong grade.
16. The strong grade's typed evaluation lineage proves only content-digest nonoverlap. The reference CLI/HTTP process edges physically create their reported worlds, but `internal/reduce`, the store authority, and the grade do not independently prove physical execution or freshness.
17. The wall limit is a configured cooperative deadline, not a preemptive runtime or elapsed-time audit. The reducer checks it before and after synchronous callbacks; reference process edges must enforce their own child deadlines and return.
18. Transcript counter deltas are exact over recorded values, but do not prove hidden work. Resolved map-backed counts are cross-checked against typed attempt identities; unresolved or error-only trial counts remain callback-reported trusted-edge accounting.

## Locked package edges

```text
typed CLI/HTTP providers -> internal/reduce (pure generic search + logical draft)
internal/store           -> internal/reduce (publish/reopen exact draft; opaque capability)
internal/reduction       -> internal/reduce + internal/store (sole authoritative finalizer)
```

An architecture test must reject any `internal/reduce` import of Git, world, CLI, HTTP, store, server, or the outward finalizer; any public constructor for the store capability; and any authoritative grade constructor outside `internal/reduction`.

## Locked neighbor semantics

- Provider order is canonical by rule priority, locus, transform priority, then child digest; duplicate child stimuli collapse to the first attribution.
- Proposal identity binds parent/child stimulus digests, rule name/version, locus, bounded transform priority, exact before/after measure tuples, and the reducer-set digest that itself binds the scope.
- CLI never mutates executable, base argv, or CWD. HTTP v1 never mutates method or path. Pinned fixture/seed anchors are outside the neighborhood.
- Present-empty and absent remain distinct. Ordered argv, query, and header members retain order and duplicate multiplicity after removal/shrink operations.
- Every child is rebuilt through the existing typed stimulus constructor, must replay from its recorded recipe to the same digest, and must strictly decrease under the same named measure definition.

## Nonclaims

U5 will not establish global minimality, root cause, semantic equivalence, correctness, physical execution freshness, hidden evaluator work, elapsed wall time, replay freshness, artifact authorship, security, production readiness, cross-platform behavior, or market adoption. A store capability proves only that one exact logical sweep draft was atomically published and reopened under the reference filesystem policy. A replay receipt records bounded digest noncollision only. didrun receipts prove only the commands that actually ran.
