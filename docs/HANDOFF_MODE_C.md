## Why the original idea was killed

The first concept was a local, vendor-neutral agent execution runtime with a durable event journal, resume/replay/fork, evidence, and a causal viewer. Direct inspection showed [`nelsonwerd/wake`](https://github.com/nelsonwerd/wake) already implements that exact semantic spine deeply. Do not drift back.

The assurance-graph alternative was also parked because the installed didrun already owns command recording, Git-tree binding, claim grades, commit manifests, bundles, strict verification, and HTML evidence. Countershape may reference didrun grades verbatim; it must not reproduce or strengthen them.

The behavior-to-code tracing alternative was parked because Repro, Highlight, OpenReplay, Traceway, and related work already occupy much of browser/session replay, cross-layer traces, source mapping, and agent-facing context.

## Red-team-locked Choicepoint kernel

A Choicepoint contains:

- exact candidate Git tree ids and a regular/executable-blob-only materialization manifest;
- deterministic WorldPlan, measured WorldInstances, and a declared ComparisonEnvelope that never claims behavioral compatibility;
- original and locally minimized replayable stimulus;
- `OBSERVED_STABLE(k/k)` evidence plus physically new confirmation attempts; no execution-evidence reuse;
- post-capture-policy CapturedObservation digests and exact projected candidate-to-fingerprint OutcomeMap;
- `UNSTABLE`, `UNCOMPARABLE`, and `INCOMPLETE` members kept explicit and out of outcome cards;
- tri-valued reduction preserving the complete labeled map, with only `UNCHANGED`, `BEST_KNOWN`, or `ONE_MINIMAL_UNDER` grades;
- blind-first human ruling: allow one/many, custom expectation, reject all, or defer; refine derives a successor;
- exact-witness scope only, no-default selected fields, nonasserted fields, and mandatory allowed/disallowed separation;
- separate DecisionRecord, deterministic ContractBundle, and fresh ContractExecution;
- Go/Node semantic parity vectors and physical Countershape-absence proof;
- receipt references without grade inflation.

The system does **not** establish global equivalence, completeness, correctness, security, maintainability, or production readiness.

## didrun discipline — exact operating rule

`.didrun/` is secret-bearing, self-ignored by didrun, excluded from tree digests, and must never be committed. A redundant root `.didrun/` ignore rule is intentionally absent because it triggers the measured didrun 0.1.0 tree-digest bug recorded in `docs/status/DIDRUN_BUGS.md`.

For every shippable build unit:

1. run every load-bearing test/lint/build/integration command through `didrun run -- <command>`;
2. inspect `didrun show --session` and declare only honest claims bound to successful events;
3. stage intentional files and commit without an AI `Co-Authored-By` trailer;
4. run `didrun seal`;
5. run `NO_COLOR=1 didrun verify --strict`;
6. on nonzero: the unit is not done—fix the cause, rerun through didrun, re-claim, commit, reseal, and reverify; never weaken/delete/relabel a failed claim.

The final commit also needs a didrun HTML report and a receipt table mapping every claimed capability to the **verbatim grade**. Anything not passed through didrun is `UNRECEIPTED`.
