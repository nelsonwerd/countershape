# Security policy

Countershape is a local research reference. It has not received an independent security audit and is not a containment boundary.

## Supported scope

Security-sensitive fixes are considered for the current Darwin/arm64 reference profile, especially exact-object admission, process lifecycle, loopback authentication, private evidence roots, inert report rendering, and exclusive file publication. Linux is cross-compile evidence only.

## Private reporting

Do not attach real captured evidence, raw reports, repository contents, credentials, home-directory paths, `.didrun` archives, or access tokens to a public issue. Report the smallest synthetic reproducer and exact commit privately to the repository owner. Rotate any credential that may have entered a raw export or process stream.

The default report only minimizes a closed fixture profile. Its redaction tests establish fixture coverage, not arbitrary-secret absence. **CONFIDENTIALITY NOT ESTABLISHED.**

## Out of scope

Countershape does not isolate hostile code, constrain host network access, establish browser/client authenticity, sign releases, generate an SBOM or provenance attestation, or certify a report as safe to share.
